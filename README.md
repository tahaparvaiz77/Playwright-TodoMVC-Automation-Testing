# Playwright TodoMVC Automation Testing

## Project Overview
Automated end-to-end testing of the TodoMVC application using Playwright.

## Technologies
- JavaScript
- Playwright
- Node.js

## Test Scenarios
- Add a todo
- Edit a todo
- Complete a todo
- Delete a todo
- Verify todo count
- Cross-browser testing

## How to Run

npm install

npx playwright test

## Run in Headed Mode

npx playwright test --headed

## Browsers
- Chromium
- Firefox
- WebKit
